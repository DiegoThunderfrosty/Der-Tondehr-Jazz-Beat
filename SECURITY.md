# Security policy

Do not publicly disclose a vulnerability that could execute code, write outside
expected directories, expose private data or load untrusted content unsafely.

Use GitHub's private **Report a vulnerability** feature if it is enabled.
Include the affected version, component, reproduction steps and expected
impact. Only the latest release receives security updates.

Never attach private audio projects, recordings, credentials, access tokens,
personal paths or third-party files to a report.
